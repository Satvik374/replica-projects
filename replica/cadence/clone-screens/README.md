# Cadence — clone screens

These are captures of the running Cadence renderer, not mockups.

The cloud browser panel available here is smaller than the app's 1120×620 desktop minimum.
For the desktop shots the app canvas was rendered at 1280×800 and scaled to 0.5 inside the panel
at devicePixelRatio 2, so the saved images are 1:1 device pixels and show the real layout. The
narrow shot is the honest panel viewport with no scaling.

| file | viewport | what it shows |
| --- | --- | --- |
| `S01-workspace.png` | 782×853 panel | first full workspace pass: project, viewer, timeline, effect controls |
| `S01-workspace-narrow.png` | 392×429 panel | the responsive minimum: panels stack and scroll rather than collapse |
| `S05-timeline-keyframes.png` | 1280×800 app, scaled capture | Title layer selected and expanded; one keyframe selected, In/Out influence fields visible |
| `S06-effect-controls.png` | 1280×800 app, scaled capture | Glow filtered in Effects & Presets and applied to the Title layer |
| `S10-render.png` | 1280×800 app, scaled capture | Render dialog in PNG frame mode |
| `export-frame.png` | 1920×1080 output | the actual PNG produced by Render ▸ PNG frame at frame 55 |
| `export-video.webm` | 1920×1080 output | the WebM produced by Render ▸ WebM video (smoke test; decoded frames not inspected) |

The demo composition is generated by the app at first run. `S05` and `S06` were taken with the
playhead at frame 55, where the title card is fully visible; the autosave was cleared before the
final pass so the demo is pristine and has no extra effects.

Known limits of this capture pass: no native 1440×900 screenshot was possible in this VM, and
Electron itself was not launched because the VM has no display.
